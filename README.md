# CodeCanvas AI | Smart Code Review & Optimization

CodeCanvas AI is an intelligent platform designed to help developers write better code. By leveraging advanced AI models via Genkit and Google Gemini, it provides instant, professional-grade code reviews and performance optimization suggestions.

## Key Features

- **Automated Code Review**: Analyzes code for strengths (pros), weaknesses (cons), and potential bugs.
- **AI-Driven Optimization**: Automatically refactors code to improve time/space complexity and adherence to best practices.
- **Language Agnostic**: Works with JavaScript, Python, C++, Java, and more.
- **Exportable Reports**: Generate and download detailed review reports for documentation.
- **Modern UI**: Built with a sleek, dark-mode interface using Tailwind CSS and ShadCN UI.
